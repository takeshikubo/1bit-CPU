# 1bit-CPU
1bit-CPU回路ハンズオン
## 設計の説明
事前情報によると、ポリシリコン層を配線として使った人は過去にいない。
配線の一部にポリシリコン層を使った。

## 工夫したポイント
構造理解を深め適用できる個所を事前に検討し適用した
金属配線（アルミや銅）と比較しメタル配線の抵抗が数 mΩ/sq 程度であるのに対し、ポリシリコンは 数十Ω/sq 程度の高いシート抵抗を持ちます。
そのため、長い距離の配線に使うと大きな抵抗が発生し、信号遅延の原因になります。
よって、今回の設計では短い配線に用いります。

## 苦労したポイント
今までに無いものを作るという課題があり、
Geminiも交えてポリシリコン層（物理特性）を構造的に活かした提案の可能性を模索・検討いたしました。しかしながら、検討の結果、妥当性・有用性を持った構成を組み上げることが難しかったです。

##検討後、見送りになったもの
### 非同期（クロックレス）1bit-CPU
検討内容: グローバルクロックを用いず、シングルレール＋ポリシリコン遅延エレメント（Bundled-Data方式）による駆動。
見送り理由: 手動入力等の代替トリガーがあれば原理的には成立し得ますが、今回の1bit-CPU評価回路の構成上、意図した動作確認・評価を実現するのが難しいと判断いたしました。

### ポリシリコンによるチャタリング防止（Debounce）RCフィルタ
検討内容: ポリシリコンのシート抵抗と基板間容量を用いた物理RCフィルタによるノイズ除去。
見送り理由: スイッチ等の物理的なチャタリング除去には100μs〜数十msオーダーの時定数が必要ですが、オンチップのポリシリコン層で確保できる遅延は数ps〜数ns程度が限界であり、物理的なサイズ制約上成立いたしません。また、今回の評価系では外部スイッチの押下回数を正確に読み取る仕様ではないため、回路としての有効性も薄いと判断いたしました。
